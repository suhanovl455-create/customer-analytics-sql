# Недельное удержание пользователей

Задача: посчитать активность пользователей после регистрации и сравнить когорты. 270 пользователей, 6 когорт с 6 июля по 10 августа 2026 года; наблюдение заканчивается 31 августа. Данные синтетические, в активности намеренно есть повторы.

Когорта — неделя регистрации с понедельника. W0 — неделя регистрации, W1 — следующая календарная неделя. Метрика для Wn: уникальные активные пользователи в Wn / все зарегистрированные в когорте. Это периодическое удержание, а не rolling retention. Активность не включает регистрацию автоматически, поэтому W0 может быть меньше 100%.

Период включается только после полного окончания календарной недели. Если когорта не успела прожить нужную неделю, в отчёте нет такой строки: это отсутствие наблюдения, а не нулевая активность. Полные недели без активности выводятся с нулём. Для устранения повторов активность сначала группируется по пользователю и неделе.

## Ограничения

Неделя регистрации для разных пользователей имеет разную оставшуюся длительность. Для сравнения ранней активации может быть полезнее окно от индивидуальной даты регистрации. По синтетическим данным нельзя заключать, что продукт реально теряет пользователей или что одна когорта качественнее другой.

В каждой когорте 45 пользователей. «—» означает неполное окно наблюдения. W1 иногда выше W0: метрика считает активность в отдельных неделях и не требует активности на предыдущем шаге. В отличие от воронки, retention не обязан монотонно снижаться.
