# Удержание и сегментация клиентов на SQL

Два учебных кейса на SQLite с синтетическими данными. Аналитические запросы находятся в SQL-файлах; Python генерирует фиксированный набор данных, запускает запросы и проверяет результат.

| Кейс | Задача | Что важно в решении |
|---|---|---|
| [Когортный анализ](01-retention/README.md) | Недельное удержание | Неполные периоды не считаются нулём, повторы событий исключаются |
| [RFM-сегментация](02-rfm/README.md) | Метрики и группы клиентов | Клиенты без покупок сохраняются, пороги и порядок правил явно заданы |

## Запуск

Python 3.9+, без дополнительных библиотек:

```sh
python3 run.py
python3 verify.py
```

Первый скрипт перезаписывает сгенерированные CSV, базы и результаты внутри двух кейсов. SQL-файлы не изменяются: можно редактировать запросы и запускать скрипт снова. Данные генерируются с фиксированными seed. Пустое поле CSV обозначает NULL.

После запуска базы `project.sqlite` можно открыть в редакторе SQLite. В `results/` лежат CSV-результаты запросов.
